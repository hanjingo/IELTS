## 出题规则

1. 注意头衔的发音及含义，并且尽量不要修改头衔的大小写；如：`Mr.`(先生), `Mrs.`(夫人), `Ms.`(女士), `Miss`(小姐，没有`.`), `Dr.`(博士)...

2. 电话号码通常以三个或四个数字为单位连续念出，如：108-544-1234

3. 地址范围由小到大，如：门牌号=>街道名=>社区名=>城市=>国家；且某一范围可能有多个表达方式，如：街道可以表示为：Road, Street, Avenue, Lane, Drive...

4. 时间和日期有多种读法，如：

   | 时间读法                                 | 时间 | 读法示例             |
   | ---------------------------------------- | ---- | -------------------- |
   | 直接读                                   | 8.30 | eight thirty.        |
   | 分钟 + past + 小时 （仅限前30分钟）      | 8.20 | twenty past eight.   |
   | 差的分钟 + to + 下一小时（仅限后30分钟） | 8.50 | ten to nine.         |
   | a quarter past + 小时                    | 8.15 | a quarter past eight |
   | a quarter to + 下一小时                  | 8.45 | a quarter to nine    |

   | 日期读法                       | 日期 | 读法示例            |
   | ------------------------------ | ---- | ------------------- |
   | 月份 + the + 日期（序数词）    | 8-3  | August the third    |
   | the + 日（序数词） + of + 月份 | 8-3  | the third of August |

   **注意**

   - 口语中一月，二月，三月可以读作first, second, third；如1-8读作the eighth of the first.
   - 有一些特殊的时长读法；如：两星期读作fortnight；十年读作decade；一世纪读作century.

5. 注意货币单位的发音，书写与转换，如：

   | 货币单位     | 符号 | 书写            | 转换       |
   | ------------ | ---- | --------------- | ---------- |
   | 美元(dollar) | ＄   | ＄+ 数字        | ＄1 = 100C |
   | 美分(cent)   | ￠   | 数字 + C        |            |
   | 英镑(pound)  | ￡   | ￡+ 数字        | ￡1 = 100P |
   | 便士(penny)  | P    | 数字 + P        |            |
   | 欧元(euros)  | €    | 数字 + € + 小数 |            |

   发音示例：＄2.50读作two dollars fifty (cents)或two fifty.

6. 注意一些约定俗成的读法：

   |                         | 读法示例                         |
   | ----------------------- | -------------------------------- |
   | 数字zero                | - 字母发音O<br>- naught<br>- nil |
   | 门牌号或公交线路，如21A | twenty one A                     |

7. 区分`-teen`和`-ty`的发音，这两类数字有三个不同点：

   - 重音：以"thirteen"和"thirty"为例，[thirteen](res/thirteen.mp3)的重音在"teen"上，而[thirty](res/thirty.mp3)在"thir"上.
   - 长短音：teen发长音的`/i:/`, 而ty是短音`/I/`.
   - 鼻音：teen的鼻音有鼻音`/n/`，而ty没有.

8. 区分单复数：

   答案只能为单数的情况：

   - 题目空格前后给出了明确的语法提示；如：题目空格前有a/an/one，或空格后是第三人称单数is/was/does

     例：Passionately communicate a clear <u>vision</u>

   - 题目出现并列，且和单数名词并列

     例：Includes: Accommodation, Car, <u>Aduioscripts</u>

   - 答案是不可数名词或特指的名词

     例：Duck races Venue: Start behind the <u>cinema</u>

   答案只能为复数的情况：

   - 题目给出语法提示；如：空格前出现any/some等前缀，空格后出现are/were/do

     例：Premier members can bring some <u>guests</u> every month.

   - 题目出现并列关系，且和复数名词并列

     例：To increase the light, the building has many internal mirrors and <u>windows</u>

   答案可同时为单数或复数的情况：

   - 题目空格的语法形式确定是单数，录音原文是复数/ 题目空格语法形式确定是复数

     例：Members should always take their <u>photo card/photo cards</u> with them.

   建议还是要多练习单复数尾音`s`，直接听出单复数。

9. 注意听录音时的一些“指示语”或“信号词”，它们可以帮助理解篇幅较长的讲话；一些常见的信号词：

   - **引出**讲话的主图或下一部分内容
   - **添加**信息或展开主题
   - 列举**事例**
   - 表述**原因**
   - 表述**结果**
   - 总结或**回指**

10. 连读和吞音的原理：

    - 连读：即相邻的两个词，前者尾部辅音音素与后者开头元音音素能够自然拼读，例：end of term.
    - 吞音：简单来说就是爆破音（包括t, d, k, g, b, p）后面跟一些辅音时，失去爆破或吞音，如put down.

    要进行连续和吞音的跟读模仿练习，熟悉这些发音习惯，从而适应音频节奏。

11. 拼写规则：

    - 拼写时一般把连在一起的相同字母读作：`double x`；例：harry读作：h-a-double r-y。
    - 注意某些奇怪的读法；例：z读作：zet。



## 题型

### 信息表格题(form completion)，笔记填空题(notes completion)，句子填空题(sentence completion)和对比表格题(table completion)

1. 阅读题目
   - 找出定位词。
   - 根据已知信息预测答案的词性，内容方向及书写形式。
2. 听题
   - 按题号顺序跟听题目，利用空格前的定位词信息把握总体听力节奏。
   - 注意排除干扰信息，跟听时边听边记。
3. 注意拼写检查和单复数。

### 地图题(map)

1. 阅读题目
   - 浏览图片信息，图中词汇在录音中基本全部原词重现，注意它们的发音和所在位置；理解图片信息并明确其所指代的事物，有时像sofa, train line, forest/trees, entrance等可能不会有文字注释。
   - 根据图上已知信息，预测建筑物或字母代表位置的方位表达。
2. 听题
   - 在街道类地图题中，两条道路交叉口，道路转弯，道路尽头等处多有出题点或有关键信息出现。
3. 注意答案词的首字母书写方式应参照地图中已给单词首字母的书写形式。

雅思听力考试中对于地图题有一些常见的方位词：

- 上下左右：up, down, left, right.
- 前后：front, back, rear.
- 内外：inside, outside.
- 中心：center, middle.
- 角落：corner, edge.
- 远近：far, near.
- 高低：high, low.
- 其它：on one's left/right, in the vicinity of, adjacent to, located behind/in front of, go straight across/to/through, cross over, turn left/right, go up/down, go back/back up, go east/west/south/north, on the east/south/west/north, opposite, facing to, be parallel to.

### 选择题(multiple choice)

1. 阅读题目
   - 利用上一个Section结尾30s的检查时间开始阅读选择题。
   - 以疑问句句型为题干的选择题，建议在听题之前将题干和选项通读。名词在原文中重现的概率较大，动词，形容词，副词等以同义替换的形式出现的概率较大，听前要重点理解词义，多灌注选项之间的的差异部分。对于补全题干型的选择题，听题之前可以将重点全部放在读取和理解选项上。
   - 选择题比较容易出题的考点涉及题干和选项中的时态，否定词，量词和程度副词等，读取信息时可以将相关内容重点标注。
2. 听题
   - 当听到录音中出现读题时标出的重点信息时，注意辨别录音中的时态，量词，程度副词，肯定或否定语气是否与卷面信息意思一致。
   - 可以适当使用排除法等答题技巧降低选择难度（**慎用**）。

### 配对题

1. 阅读题目
   - 可以比较题干，选项中内容相对简短的部分，也可以暂时不看，重点关注内容多且复杂的部分。
   - 将复杂部分进行简化，标出比较有特色的词语，如首字母大写的单词，动词，形容词和其它一些起限定作用的词。
2. 听题
   - 当听到录音中出现读题时标出的重点信息时，注意辨别录音中的时态，量词，程度副词，肯定和否定语气是否与卷面信息意思一致。



## 备考攻略

1. 要明确听力词汇与阅读，写作各项词汇的区别，听力词汇重点在于发音；建议弱化中文翻译，快速读背词汇，用词汇音频进行听写；同时要习惯按照词汇音节读背，如category，读时应认清音节ca-te-go-ry，这样才能避免在拼写时出现多写或少写字母的错误。
2. 要明确音频播放速度比自身理解速度快的原因是，考生对连读和吞音的掌握有欠缺。建议进行连读和吞音的跟读模仿练习，熟悉这些发音习惯。
3. 平时要加强快速查找关键词的能力。



## Tips

1. 快速阅读题干，不需要浪费大量的时间去读懂每个答案，抓住某几个**关键词（信号词）**即可。
2. 听力的提升是一个积累的过程，需要投入大量时间做听力练习。
3. 要有错题本和生词本，做完题目需要及时复习。
4. 注意拼写检查。
5. 一遍过，不要浪费听力间隙时间来检查已经做完的答案。
6. 注意避开一些陷阱（比如提到题干，然后否定它，让你选错）。
7. 遇到难题或不会做的题跳过。
8. 答案不区分大小写，同为大写或同为小写都可以；答案区分单复数，单复数写错没有分。
9. 已经选择的答案**切记**不要轻易修改，要相信自己的第一感觉。
10. 作答时无需使用标点符号。
11. 不要使用缩写（标准缩写除外，如：Mr, Dr, kg, km等），使用非标准缩写没分。
12. 录音中很少使用和问题中完全相同的单词，要注意同一观点的不同表达方式，以及对同义替换词的积累。
13. 对于答案很长的填空题，来不及写完，可以先用缩写或者记号代替，听完后还原。
